## Security Policy

### Supported Versions
The latest commit on the default branch is supported. Please keep your fork up to date.

### Reporting a Vulnerability
If you discover a security vulnerability:
- Do not open a public issue.
- Email the maintainer listed in the README or open a private security advisory on GitHub.
- Provide steps to reproduce and any relevant logs.

We will assess and respond as quickly as possible. Thank you for helping keep the project secure.
